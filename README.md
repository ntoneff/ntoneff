## What I'm building

- **[org-sim](https://github.com/ntoneff/org-sim)** --- Agent-based value stream simulator modeling how work flows through organizations. Built with Python, Mesa, and NetworkX. Demonstrates system dynamics, bottleneck identification, and Theory of Constraints principles through interactive simulation.
- **[game-one](https://github.com/ntoneff/game-one)** --- From-scratch 2D isometric strategy game inspired by Lords of Magic (1997). Python + pygame-ce rendering engine with GSA painterly art, shore autotile system (46-rule Unity Rule Tile extract), delta-time movement, lerp-based eased node travel, and a turn-based combat scene.
- **[vi-dashboard](https://github.com/ntoneff/vi-dashboard)** --- Full-stack AI lifemate system running on a Tailscale-connected Mac Mini. A Claude Agent SDK-powered VI (Mass Effect-inspired personality) manages an Obsidian vault for GTD, reads/writes a SQLite health database, and controls its own Google Calendar. Health and environmental data pipelines sync from Withings, Fitbit, PurpleAir, NWS, OpenUV, and Google Air Quality. A recipe-driven career intel engine scores employer/client opportunities using data from Greenhouse, Coresignal, Layoffs.fyi, and Financial Modeling Prep. Two-pass Claude inbox triage turns photos of post-its or brain-dump text into structured vault actions (projects, tasks, codex entries). React dashboard with voice interface (Whisper STT, ElevenLabs TTS, wake word), live WebSocket updates, vault health monitoring, habit tracking, workout log parsing with muscle-group inference, acts-of-service ledger, and daily AI synthesis.
